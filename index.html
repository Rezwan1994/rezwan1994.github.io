I’m an AI-empowered Software Engineer with 8+ years of experience designing, developing, modernizing and supporting business-critical software solutions. My core expertise is C#, ASP.NET Core / .NET, RESTful Web APIs, SQL Server, Oracle, Angular, microservices, clean architecture, real-time systems, cloud services and database optimization.
